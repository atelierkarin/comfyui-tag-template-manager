# v0.4.0 Tag Main Implementation Plan

**Goal:** Add ordered bundle collection and CLIP conditioning while preserving existing nodes.

**Architecture:** A bundler outputs an ordered list of existing bundles; a new Main composes through the existing service and invokes the standard CLIP encoding interface. The frontend traverses the bundler for text preview.

**Tech Stack:** Python 3.10+, ComfyUI, JavaScript, unittest and Node.js.

**Spec:** `docs/superpowers/specs/2026-11-20-v0.4.0-tag-main-design.md`

## Global Constraints

Preserve node identifiers, existing ports and state, single-user checks, live execution, prompt composition and snapshot behavior. Do not modify installed copies or user data. Direct preset selection is deferred.

## Review Focus

- Sparse and duplicate connections preserve order.
- Empty input encodes the empty or free text normally.
- Missing and unsupported preview sources report errors.
- Preview cannot overwrite a newer result with an older response.
- Standard CLIP tokenization and scheduled encoding pass errors through.

2. Add failing UI tests for bundler traversal, order, reroutes and errors; implement preview traversal and register the new Main; run JavaScript tests.
3. Update both READMEs and changelog, run all project checks, and review the complete change. Record any unavailable ComfyUI integration checks.
