# v0.3.0 Editor Implementation Plan

> 実装は `superpowers:executing-plans` で行う。

**Goal:** 多数のブロックを１件ずつ選んで編集できるようにし、既存の保存・選択・プリセットを維持する。

**Architecture:** `web/editor.js` の下書きとは別に選択中ブロック ID を画面内に保持し、既存の `editor-state.mjs` の操作を使う。テンプレート形式と API は変更しない。

**Tech Stack:** JavaScript、Node.js DOM シミュレーション、Python unittest。

**Spec:** `docs/superpowers/specs/2026-11-17-v0.3.0-editor-design.md`

## 制約と確認点

- 既存 ID・出力順・Live／Snapshot・競合時の下書きを維持する。
- 同名、空リスト、削除後の選択、未保存の切替、保存失敗後の選択と内容をテストする。
- 実機環境が使用できない場合は未検証と記録する。ユーザーデータやインストール済みコピーは変更しない。
