# v0.3.0 エディター改善・統合検証 設計案

作成日：2026-11-17

状態：レビュー用提案。未実装。

対象：単一ユーザーモード、既存のテンプレートとワークフロー。

## 目的と範囲

ブロック数の多いテンプレートでも、目的のブロックを見つけ、内容を確認し、編集・整理しやすくする。あわせて v0.2.0 のデータ保全・再現性機能を対象 ComfyUI 環境で検証し、次のリリース情報を整合させる。

完了の目安は、多数のブロックを持つテンプレートで、対象の選択、編集、順序変更、複製、削除、プリセット編集を迷わず行え、保存・再読み込み後も意図した内容と順序が維持されること。既存ワークフローの互換性と未保存の下書きの保護も維持する。

バックアップの一覧・削除機能、自動削除、マルチユーザー対応、プロンプト構文の意味解析、プレビューの外部ノード対応は対象外とする。実機検証で不具合が見つかった場合は、影響と修正範囲を評価し、必要な修正をこのバージョンに含める。

## 現状と方式の比較

現在は全ブロックが折りたたみ可能な項目として並び、各項目の中で編集・移動・複製・削除する。プリセットは全ブロックのチェック欄を表示する。ブロック ID、順序、プリセットの参照は保存データの一部であり、画面だけの変更でも維持が必要。

1. **選択したブロックを同じ画面内で編集する（推奨）**：順序付きの選択欄と、選択中の１件の編集欄を表示する。多数の編集欄を同時に表示せず、別ダイアログの下書き管理も不要。一覧と編集欄の対応を明確にする必要がある。
2. **現行の折りたたみ表示に検索・一括開閉を追加する**：従来の操作を維持しやすいが、長い一覧やプリセット欄によるスクロールは残る。
3. **選択したブロックを別ダイアログで編集する**：一覧を簡潔にできるが、ダイアログ内の確定・取消とテンプレート全体の保存の違いを扱う必要がある。

以下は 1 を採用した設計提案であり、画面詳細を含めレビューで変更可能。選択中の内容は編集欄で確認できるため、独立した Block Preview ダイアログは設けない。

## ブロックの選択と編集

- Blocks に追加ボタン、現在のブロック順に並ぶ選択欄、選択中ブロックの編集欄と操作ボタンを置く。選択肢は名前と ID を表示し、同名でも区別できる。ブロックがない場合は空状態を示し、対象を要する操作を無効にする。
- 選択中の名前、チャンネル、排他グループ、既定 ON/OFF、タグを編集できる。編集は既存のテンプレート下書きに直接反映し、未保存状態とする。選択を切り替えても変更は下書きに残り、テンプレート全体の Save までサーバーには保存されない。名前変更は選択肢にも反映する。
- 追加時は新しい ID を持つブロックを末尾に作り選択する。複製は選択中の直後に新 ID で作り、既定 OFF として新しいブロックを選択する。既存プリセットには自動追加しない。
- 上下移動は選択中の ID を維持して隣接項目と順序を交換する。先頭・末尾で移動できない方向は無効とする。順序は出力順に影響するため、選択欄にも反映する。
- 削除はブロックとプリセット参照の削除を明示して確認する。キャンセル時は変更しない。削除後は同じ位置の次の項目、なければ直前の項目を選び、残りがなければ空状態にする。
- 選択状態は画面内のみで管理し、テンプレートやワークフローに保存しない。同じ下書きの再描画や保存成功時は対象 ID が存在すれば選択を維持する。別テンプレートの読み込み、新規作成、再読み込みでは先頭を選択する。画面を閉じる、別テンプレートに移る、再読み込みする場合などの未保存確認と、保存失敗・競合時の下書き保持は維持する。
- 編集欄と選択欄には明確なラベルを付け、キーボードで選択・操作できる標準要素を用いる。フォーカスと入力中の値を不用意に失わないよう、名前・タグの入力ごとに編集欄全体を再生成しない。

## プリセットと互換性

プリセット編集は既存のチェック欄方式を維持し、現在のブロック名と順序を表示する。ブロックの追加・名前変更・移動・複製・削除後に表示と参照を整合させる。排他グループは既存どおりチャンネルごとに適用し、既存の選択操作の意味を変えない。

テンプレートのスキーマ、テンプレート／ブロック／プリセット ID、ノード種別、出力順、保存済みノード状態の形式を変更しない。Live と Snapshot、revision による競合検出、保存・削除前のバックアップは既存の動作を維持する。画面変更に伴う API 変更は予定しない。Python 側の検証や保存先の安全性を緩めない。

## 統合検証

既存の Python・JavaScript チェックを実行し、画面テストでは少なくとも空状態、同名ブロック、選択切り替え後の未保存編集、追加・複製・移動・削除、プリセット参照、保存失敗・競合時の下書き維持、保存後の選択維持を確認する。DOM シミュレーションは実ブラウザー検証の代わりにはしない。

対象 ComfyUI で、テスト用データとワークフローを使い以下を確認する。実行環境が利用できない場合は未実施を明記する。開発チェックアウトと実行用コピーが異なる可能性があるため、実行対象を確認し、稼働中のインストールやユーザーデータを無断で変更しない。

- 多数のブロックの編集、順序変更、プリセット編集、保存、画面再読み込みとワークフローの保存・再読み込み。
- 既存 Live ワークフローの読み込み、テンプレート更新後の出力更新、欠損・破損時の明確なエラー。古いキャッシュ結果を返さないこと。
- Snapshot の作成・更新・Live 切り替え、ライブラリ変更・欠損後の Snapshot の表示と実行、保存・再読み込み。
- インポート／エクスポート、ID 衝突、バックアップ復元、複数画面での保存競合と下書き保持。
- 対応する接続におけるプレビューと実出力の一致、および既知のプレビュー制限の表示・説明。
