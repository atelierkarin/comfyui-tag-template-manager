# Nodes 実装計画

対象: [Phase 2 Nodes 設計書](ComfyUI_Tag_Template_Manager_Nodes_Design_v1.md)。ComfyUI 0.22.0、Python 3.10 以上、単一ユーザーのみ。親リポジトリにコミットしない。

1. ノード状態の解析、完全な選択状態の検証、固定ポート順の結合をテストし、`services/node_service.py` と `nodes.py` を実装する。テンプレートは実行ごとに読み直す。
2. 読み取りとプレビューの API を追加し、正常・未選択・破損・不正状態・マルチユーザー拒否を検証する。
3. ComfyUI 拡張の選択 UI、保存される状態、明示的なプレビュー更新を実装する。非同期応答順序と切替時の排他を確認する。
4. 実際の ComfyUI の読み込みと API・実行経路を、ユーザーデータをワークスペース内に分離して検証する。ブラウザーで確認できない項目は未検証として記録する。
