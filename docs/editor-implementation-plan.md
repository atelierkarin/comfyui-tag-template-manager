# Editor 実装計画

仕様: [Editor 設計](ComfyUI_Tag_Template_Manager_Editor_Design_v1.md)、全体設計。Python 3.10 以上、標準ライブラリと ComfyUI の既存 aiohttp を使用。

1. API の新規作成・更新・削除について、正常、ID 衝突、パスと本文の不一致、検証失敗、未存在、マルチユーザー拒否を先にテストし、ストアを通すルートを実装する。
2. ブロック・プリセットの複製、並べ替え、削除時の参照更新と排他切替を純粋関数としてテストし、エディターの状態操作を実装する。
3. モーダル UI に一覧・検索、フォーム、保存／別名保存／削除・破棄確認を実装し、Template Node から起動できるようにする。
4. 全自動テストと JavaScript の構文確認を実行し、使用方法とブラウザー未確認の制約を README に記載する。
