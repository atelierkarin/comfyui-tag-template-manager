# Phase 3 Editor 設計

全体設計の Editor 段階を実装する。`Tag Template` のボタンからモーダルを開き、テンプレート一覧・名前やカテゴリーの検索、作成・編集・別名保存・複製・削除、ブロックとプリセットの編集を行う。操作はノード選択状態と分離し、変更破棄と削除には確認を求める。保存された ID は固定する。ブロック削除時はプリセットの参照も除去する。排他グループの矛盾はサーバーの Core 検証で拒否し、理由を表示する。

読み取り API に作成・更新・削除を追加し、既存 `TemplateStore` を使って検証・保存する。作成時に ID が衝突したら 409 として上書きしない。更新はパスと本文の ID が一致する既存テンプレートのみを対象とする。マルチユーザーは従来どおり拒否する。エディターで保存後、起動元ノードの一覧を更新し、既存の選択状態を勝手にリセットしない。

インポート／エクスポート、バックアップ、同時更新の競合検出、Snapshot は Stability 段階とする。ブラウザー手動確認は、利用中の ComfyUI を妨げないよう今回実行せず、独立したテストで検証する。
