# ComfyUI Tag Template Manager

[English](README.en.md) | 日本語

キャラクター、衣装、背景、品質タグなどをローカルのテンプレートとして管理する ComfyUI カスタムノードです。再利用したいタグをブロックに分け、ワークフローごとに選択してプロンプトを組み立てられます。

## 主な機能

- テンプレートとブロックの作成、編集、複製、並べ替え、削除
- ブロックの有効／無効切り替えと、選択状態をまとめて適用するプリセット
- Positive／Negative の個別管理と、チャンネルごとの排他グループ
- 複数テンプレートと自由入力の結合、一時的なタグ除外、結合結果のプレビュー
- `Tag Template` からの STRING 直接出力と、ワークフローへの選択状態の保存
- Bundler による入力の集約と、CLIP を使った Conditioning 出力

## インストール

ComfyUI の `custom_nodes` フォルダーで、このリポジトリをクローンします。

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/atelierkarin/comfyui-tag-template-manager.git
```

ComfyUI を再起動し、ブラウザーを再読み込みしてください。ノードは `Tag Template Manager` カテゴリーに表示されます。

ComfyUI 0.22.0 で動作を確認しています。Python 3.10 以上が必要です。追加の Python パッケージは不要です。現在は ComfyUI の単一ユーザーモードに対応しています。

## 基本的な使い方

1. `Tag Template` ノードを追加し、**Edit library** を開きます。
2. **New** でテンプレートを作成し、名前とタグのブロックを追加して **Save** します。必要に応じてプリセットも作成できます。
3. テンプレートを選び、使用するブロックにチェックを入れます。プリセットを選択した後も、個別に変更できます。選択状態はノードごとにワークフローに保存されます。
4. そのまま使う場合は、`Tag Template` の `positive` または `negative` 出力を、CLIP Text Encode などの STRING 入力に接続します。
5. 複数テンプレートを使う場合は、各 `bundle` 出力を `Tag Template Bundler` に接続し、その `bundles` 出力を `Tag Main (Encode)` に接続します。Bundler は最大８入力を番号順に結合します。
6. モデルの CLIP を `Tag Main (Encode)` の `clip` に接続し、`channel` と自由入力の `text` を設定します。`text` と `conditioning` を出力します。Positive と Negative の両方が必要なら Main を２つ用意し、同じ Bundler を接続します。Bundler 未接続でも自由入力を使えます。

テキストのみ必要な場合は、`Tag Main (Encode)` の代わりに `Tag Main` を使えます。こちらも Bundler の `bundles` 出力を接続します。v0.3.0 以前の `Tag Main` の８個の Bundle 入力は廃止されたため、既存ワークフローは Bundler を追加して接続し直し、プレビューと出力を確認してください。自動移行は行いません。

**Update preview** は結合テキストを表示し、CLIP のエンコードは行いません。入力や接続、テンプレートを変更した後は再度更新してください。プレビューは `Tag Template`、Bundler と通常の Reroute に対応しています。自由入力などのウィジェットを外部ノードに接続した場合は、プレビューでは評価できません。新ノードを含むワークフローは旧版のプラグインでは利用できません。

### ブロックとプリセット

各ブロックに Positive／Negative、既定の ON／OFF、任意の排他グループを設定できます。同じ排他グループでは、同じチャンネル内で一度に 1 ブロックだけを有効にできます。Positive と Negative は別々に判定されます。

テンプレートを初めて選択したときは各ブロックの既定状態が使われます。プリセットは必須ではありません。エディターでは **Block** から対象を選んで編集・並べ替え・複製・削除できます。別のブロックを選んでも変更は下書きに残り、テンプレート全体の **Save** で保存されます。

**Format tags** は選択中ブロックのタグを整形します。トップレベルのカンマの間隔と平文タグの余分な空白・改行を整理し、括弧内やエスケープされた部分は保守的に扱います。括弧の不一致など、構文を安全に判定できない場合は変更しません。整形結果を保存するには **Save** が必要です。

### 一時的なタグ除外

`Tag Main` の `exclude` に除外したい平文タグをカンマまたは改行区切りで入力します。テンプレート自体は変更されません。

たとえば `ribbon` を指定すると、`ribbon` は除外されます。大文字・小文字は区別しません。タグ全体が一致する場合に限るため、`hair ribbon` や `(ribbon:1.2)` は除外されません。括弧やエスケープを含む複雑な構文は保守的に扱います。

## 保存と再現性

テンプレートは ComfyUI のユーザーディレクトリ内の `default/tag_templates/` に、テンプレートごとの JSON ファイルとして保存されます。標準設定での場所は `ComfyUI/user/default/tag_templates/` です。バックアップや移行には、このフォルダーをコピーしてください。

エディターの **Export saved** で保存済みテンプレートを JSON として出力し、**Import** で UTF-8 JSON（1 MiB 以下）を取り込めます。インポート時とエクスポートするコピーには各ブロックに上記のタグ整形を適用します。エクスポートは保存済みデータを変更せず、未保存の編集も含みません。JSON 文字列に改行が残る場合は、JSON の規則に従い `\n` で表現されます。ID が重複した場合は別 ID を指定するかキャンセルできます。既存ワークフローの参照は変わりません。1 MiB を超えるテンプレートの移行にはフォルダーをコピーしてください。

保存・削除の前には元のデータを `tag_templates/.backups/` に保存します。**Restore backup** でテンプレート ID と日時・名前を確認して復元できます。バックアップは自動削除されないため、フォルダーも含めて定期的にバックアップし、必要に応じて容量を管理してください。競合時は下書きを保持し、**Save As / Duplicate** で別 ID に保存するか、**Reload saved** で下書きを破棄して再読み込みできます。外部ツールとの同時編集は完全には防止できません。

通常は **Live モード**です。ワークフローは実行時に最新のテンプレートを読み込むため、ライブラリの編集により過去のワークフローの出力が変わることがあります。テンプレートが欠損・破損した場合は、空の結果に置き換えずエラーを表示します。**Create snapshot** はテンプレート内容と選択をワークフローに保存し、その後のライブラリ変更や欠損から独立させます。**Update snapshot** で現在のライブラリ版を取り込み、**Switch to Live** で Live に戻せます。Snapshot を保存したワークフローはテンプレート内容を共有相手にも渡し、古いバージョンのプラグインでは利用できません。

テンプレートの編集後は、既存ブロックの選択を維持し、新しいブロックに既定状態を適用します。既存選択と同じチャンネル・排他グループで競合する新規ブロックは OFF になります。

## 現在の制限

- マルチユーザーモードには未対応です。
- 外部ツールによる同時編集には競合検出の限界があります。
- 出力の空白や区切りは整えますが、複雑なプロンプト構文の意味解析は行いません。重複除去は安全に扱える平文タグに限定されます。
